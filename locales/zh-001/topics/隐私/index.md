# 隐私

本网站在您的浏览器中保存什么、为什么保存，以及不保存什么。

## 在您的浏览器中保存的内容

本网站在您浏览器的本地存储（localStorage）中保存两项设置，且仅在您于页眉中选择之后才保存：

| 键 | 保存的内容 | 示例 |
|---|---|---|
| `epr-theme` | 您选择的颜色主题，或 `system`（跟随设备的浅色或深色设置） | `dark` |
| `epr-text-size` | 您选择的文字大小 | `large` |

每个值都是一个简短列表中的一个词。它表示一项设置，而不是一个人：不包含姓名、账户、地址、标识符，也不记录您阅读过的页面。首次访问时，在您更改设置之前不会保存任何内容。

## 原因

使您选择的主题和文字大小在下一个页面和下次访问时保持不变，并让页面在显示之前就以这些设置绘制。

## 不保存的内容

- **不使用 Cookie。** 主题选择器可以把选择保存在 Cookie 或本地存储中。本网站没有能够读取 Cookie 的服务器，因此只使用本地存储。
- **语言和区域**来自页面地址，例如 `/locales/zh-cn/`。更改语言会把您带到该页面的另一种语言版本。不保存任何内容。
- **时区**由选择器显示，不保存。
- **搜索**在页面中运行。您搜索的内容出现在结果页面的地址中，本网站不保存。
- **分享**仅在您选择时才打开您选的服务（电子邮件、LinkedIn 或 Bluesky）。在此之前不发送任何内容。
- **没有分析、广告或跟踪**，也不加载来自其他网站的内容。

## 托管

本网站托管在 GitHub Pages 上。GitHub 表示，访问 GitHub Pages 网站时，访问者的 IP 地址会出于安全目的被记录和保存（[GitHub 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages#data-collection)）。该记录属于 GitHub，受 GitHub 隐私声明约束。本项目无法查看。

## 删除已保存的内容

重新选择这些设置，或在浏览器设置中清除本网站的数据。两个键会一并删除。

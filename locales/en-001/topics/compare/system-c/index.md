# System C

A UK supplier of health and social care software.

A note from public sources, read on 4 November 2026. Nothing here was verified by using the product. Vendor claims are claims. This is not a product review, and "not found" means only that the sources read did not say.

## What it is

System C’s products include the CareFlow EPR, formerly Medway, BadgerNet Maternity and Neonatal, ChemoCare and Liquidlogic social care systems. Graphnet, which supplies shared care records, is a separate company in the same alliance.

## Care settings

The vendor states acute, emergency, theatres, outpatients and pharmacy. Maternity and neonatal, and social care, are specialist strengths. Mental health was not found on the pages read.

## Comparison

| Area | System C | This project today |
|---|---|---|
| Scope | Acute EPR, pharmacy, maternity and social care | Scaffold: identity, consent, allergies, observations, referrals, audit |
| Interoperability | FHIR claimed; NHS data standards | FHIR R4 and R5 reads for three resources; HL7 v2 ADT inbound |
| Mobile and patient access | Connect app (vendor) | Mobile layout and patient portal not built |

## Implications for this project

Scope should stay narrow, as comparable breadth would take years. Medicines safety requires its own hazard analysis. Separate maternity and oncology products suggest that specialty views may need their own data structures.
